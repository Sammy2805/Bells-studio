# Bells — Portfolio Starter

This is a lightweight starter for a dark-mode, neon-accent designer portfolio. It includes:

- `index.html` — site scaffold with Hero, Portfolio, Services, About, Contact.
- `css/styles.css` — design tokens, layout, and animations.
- `js/scripts.js` — minimal interactions (reveal, tilt, magnetic CTA, profile parallax).
- `assets/` — simple SVG placeholders.

How to use:

1. Open `index.html` in a browser.
2. Replace `assets/flyer-motion.svg` with a poster and update `js/scripts.js` video `src` when you have a motion file.
3. Optimize images and replace SVG placeholders with final assets.

Accessibility notes:
- All interactive items are keyboard-focusable and have aria labels where applicable.
- Respect `prefers-reduced-motion` is implemented in CSS.
